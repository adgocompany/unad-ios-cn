# UNAD-iOS-old

## Project scope

- Legacy UNAD iOS SDK and its `TestAdgo` demonstration target.
- Objective-C implementation with Xcode project validation.

## Working conventions

- Make narrowly scoped, backward-compatible SDK changes.
- Do not commit credentials, tokens, or passwords.
- Validate changes with the relevant Xcode build or test command before handoff.
- Do not push or deploy unless explicitly requested.
